# DSE 理科冲刺台

2027 DSE 重考生学习辅助工具（数学 / 化学 / 生物 / 经济），单文件 HTML，离线可用。

## 功能
- 今日卡：按星期自动显示学习日程（大课 / 一对一 / 预习标签）+ 今日三件套
- 闪卡：四科 66 张知识点卡，翻卡自测，"记住了 / 再练"自动维护复习队列（★ 得分技巧卡）
- 错题本：科目 / 错因 / 知识点登记与筛选，本地留存
- 周复盘：四问清单一键生成文本，可复制发送给教练
- 设置：当前进度周数、目标速览、数据重置

## 使用
- 直接打开 https://<owner>.github.io/dse-studydeck/ 即可
- 或下载 index.html 到手机 / 电脑浏览器本地打开（无需网络）
- 数据保存在浏览器 localStorage（清除浏览数据会丢失）

## 开发
- 单文件自包含：CSS / JS 全内联，无外部依赖
- 卡片数据在 `CARDS` 对象中，按科目 key（math/chem/bio/econ）扩展即可
